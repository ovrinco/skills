# Swarm Core

1. Read the requested outcome and existing work. Define what the user can do when complete and how to observe it.

2. Split useful independent work by disjoint writable ownership. Give each assignment its inputs, outcome, dependencies, proof and return location.

3. Establish concurrent capacity from actual resources and write conflicts. Share build targets only under a lock.

4. State joining interfaces before work starts. An owner resolves integration conflicts and checks the combined outcome.

5. Keep source identity and actual test evidence. Routine repairs remain with the author. A fresh reviewer executes the final user journey and reports gaps.

6. Use the user's authorized execution tool. A planning request produces assignments and starts no workers by itself.
