# swarm-campaign

Full coordinated-work method with source-preserving directives, coherent ownership, meaningful review and runnable pack validation.

Read SKILL.md for the complete workflow and inspect examples/ before real use.

## Requirements

Python3 standard library; no standing agent server is needed for validation.

## Receiving check

From this directory run:

    python3 tests/smoke.py

## Boundaries

The portable checked-source contract is supported. House tracker/account/constitutional adapters require separate integration. Validation does not launch agents or prove the produced software.

First-party code is covered by the collection Apache-2.0 LICENSE. Examples are invented. Source/adaptation provenance is in SOURCE_BASIS.json.
