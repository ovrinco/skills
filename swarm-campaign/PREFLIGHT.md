# Release preflight

Check the exact original requirement and source hash. Every requirement is served or explicitly deferred. Tasks have real inputs, disjoint write ownership, acceptance and completion evidence. Consumer dependencies are accepted. Protected state and execution/resource authority are explicit.

Run the pack checker. Review the semantic scope and the actual deliverable journey. Validate dependency tools and paths. Confirm the selected model/effort/transport without changing persistent accounts. Budget source/build/archive bytes. A source-only or postponed result needs accurate standing. Missing checks remain pending.

Before completion walk the actual entry point, normal use and meaningful failure/recovery. Obtain independent non-author evidence and report gaps honestly.
