# Storage research
Research question and judging rubric are in this complete prompt.
```
You are a storage-engine reviewer. Produce a comparison with dated primary sources.
Fixed facts: SQLite stores local pump-state history. The application operates offline.
Observed defect: the supplied reproduction loses the last uncommitted observation after a forced stop.
Compare three recovery strategies, their failure boundaries and operational requirements.
Label estimates and name the evidence that would falsify each recommendation.
Deliver the complete report as one downloadable Markdown file named storage-review.md.
The chat reply is one sentence identifying that file.
```
