# Hand off

Choose the artifact the receiving person or session needs. Read named existing work before describing it. Preserve requirements, source locations and standing, observed results, unresolved choices and a concrete first action.

## State of play
Keep a compact current state, replacing stale claims instead of appending an unbounded diary. Include when checked, the author/session, outcome, applicable rules, installed/accepted artifacts and recovery route, active owners, remaining work and real dependencies. A restart guide names exact versions and supported entry points. A paused task also needs the actual stop authority, retained state and continuation prerequisites.

## Brief
Explain the problem, success condition and a plausible false success. Carry the actual requirements and their evidence, completed useful work and the sources the recipient needs. Include owned write scope, resources, completion checks and return path. The next useful action should be clear without reconstructing hidden history.

A reader with local access can use precise source locations. A reader without access needs the actual necessary material in the pack. Model/tool/effort choices are execution settings for the receiving environment. A continuation prompt can point to the brief rather than duplicate it.

## Blocker report
Report a real dependency or exhausted recovery with affected outcome, command/environment, exit status and a short redacted log excerpt. Distinguish proven, attempted, inferred and unknown facts. Name preserved state, unaffected work and the action that would unblock the held part.

Routine repair stays with the authorized owner. Do not turn a recoverable failure into an unnecessary handoff. Preserve failure evidence before a retry replaces logs.

## Context pack
State the recipient and purpose, select a complete small file set and price total bytes before copying. Provide an entry README and relative-path manifest with sizes, hashes and file purposes. Verify copies. References must resolve within the pack or identify an unavailable external source.

Inspect for secrets, personal records, unpublished material and unsafe artifacts. Follow the user's actual recipient/sharing authority. Local pack creation does not send it. Keep original records intact.

## Receiving check
Recheck live claims against actual files/processes. Mark inherited unverified claims. State uncertainty and the most important review points. Have a fresh reader identify state, evidence and next action from the brief alone. A checksum proves copied bytes; it does not establish that the context is enough.
