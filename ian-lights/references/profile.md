# Supported profile

The board exposes a 241-position whole-device buffer with zone lengths 1,80,80,80. The measured fan span is in zone index 2, at whole-device offset 81. Centers use positions 0–7 and rings 8–27 within that zone, and the driver validates zone length before changing it. Both RAM modules receive ten equal Direct-mode pixels. Fan red/green correction does not apply to RAM. A matching SDK buffer does not establish visible light output. Confirm actual wiring and device/zone identity; refuse a mismatched profile. OpenRGB must already be installed and its SDK endpoint intentionally available. Review the control.py connect fallback to a user service before integration. No service is installed or started by the software tests. The original panel can lose motherboard sync after long suspend; recovery requires a hardware-specific procedure. Current state and presets are operator data, outside this source package.
